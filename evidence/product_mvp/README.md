# Preserved EQG MORPH MVP evidence

This folder groups the source artifacts for two previously reported hardware runs:

- `report-4.json` and `summary-2.txt`: Kingston run.
- `report-5.json` and `summary-3.txt`: Fez run.
- `kaggle.ipynb-20.txt` and `kaggle.ipynb-21.txt`: submitted notebook snapshots for those runs.

These files are retained byte-for-byte; only their repository location changed. Reviewed notebook templates are separate under `notebooks/eqg_product/`. Run `python scripts/validate_product_evidence.py` from the repository root to check report-summary consistency. This is not an independent hardware reanalysis.
